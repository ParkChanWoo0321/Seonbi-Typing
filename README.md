# 선비타이핑 🖋️

**선비타이핑**은 고전 문장과 전통 언어 표현을 쉽고 재미있게 학습할 수 있는 웹 기반 학습 서비스입니다.

어렵게 느껴질 수 있는 고전 문장을 단순히 외우는 방식이 아니라, 문장의 뜻을 이해하고 직접 순서를 맞추고 타이핑하면서 자연스럽게 익힐 수 있도록 구성했습니다.

## 서비스 소개 📚

최근에는 짧은 콘텐츠와 신조어, 줄임말 중심의 언어 사용이 많아지면서 고전 문장이나 사자성어, 전통적인 표현을 접할 기회가 줄어들고 있습니다.

선비타이핑은 이러한 고전 언어 표현을 현대적인 방식으로 다시 풀어내고, 누구나 부담 없이 학습할 수 있도록 만든 서비스입니다.

사용자는 고전 문장의 원문, 독음, 뜻을 확인하고 단계별 문제 풀이를 통해 문장의 의미를 반복적으로 학습할 수 있습니다.

## 주요 기능 ✨

### 단계별 문제 풀이

선비타이핑은 고전 문장을 3단계로 학습합니다.

먼저 단어 순서를 맞추며 문장의 구조를 익히고, 다음으로 문장을 보면서 타이핑합니다. 마지막 단계에서는 문장을 보지 않고 직접 입력하면서 내용을 얼마나 이해했는지 확인합니다.

### AI 훈장님 피드백

사용자가 답변을 제출하면 AI 훈장님이 정답 여부와 해설을 알려줍니다.

단순히 맞고 틀림만 알려주는 것이 아니라, 사용자의 답변이 어떤 부분에서 맞았는지 또는 부족했는지를 설명해 주어 이해 중심의 학습이 가능하도록 했습니다.

### 학습 기록 관리

사용자가 푼 문제는 기록으로 저장됩니다.

이전에 풀었던 고전 문장, 입력한 답변, 정답 여부, 해설을 다시 확인할 수 있어 복습에 활용할 수 있습니다.

### 문패 등급 시스템

꾸준한 학습을 유도하기 위해 전통 관직 명칭을 활용한 문패 등급 시스템을 적용했습니다.

문제를 풀수록 경험이 쌓이고, 도사부터 영의정까지 단계적으로 성장하는 재미를 느낄 수 있습니다.

## 서비스 흐름 🔄

회원가입과 로그인을 한 뒤, 사용자는 고전 문장 문제를 시작합니다.

문제는 단어 순서 맞추기, 보고 타이핑, 안 보고 타이핑 순서로 진행되며, 풀이가 끝나면 AI 훈장님 피드백과 해설을 확인할 수 있습니다.

완료된 문제는 학습 기록에 저장되고, 사용자의 풀이 수와 진행도에 따라 문패 등급이 반영됩니다.

## 기대 효과 🌱

선비타이핑은 고전 문장을 더 쉽고 친근하게 접할 수 있도록 돕는 서비스입니다.

사용자는 짧은 시간 안에 부담 없이 학습할 수 있고, 반복적인 문제 풀이를 통해 어휘력과 문해력을 자연스럽게 향상시킬 수 있습니다.

또한 고전 언어 표현을 디지털 학습 콘텐츠로 재해석함으로써, 전통 언어 자산의 대중화와 보존에도 기여할 수 있습니다.
